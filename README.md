# 따라미 (ddarami) · 0.1.0

유튜브 영상을 보며 악기를 연습하고, 같은 연습 템포의 드럼만으로 전환하는 Chrome 확장 프로그램입니다. 서버, 로그인, 외부 음원 없이 동작합니다.

## 설치

1. ZIP 압축을 풀어 `ddarami` 폴더를 준비합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
5. 일반 유튜브 영상(`https://www.youtube.com/watch?v=...`)을 열거나 기존 탭을 새로고침합니다.
6. 처음에는 페이지 오른쪽 위에 **따라미** 연습 패널이 표시됩니다. 제목이나 여백을 끌어 원하는 곳에 놓으세요. 버튼 안에서 누르고 놓으면 실행되고, 버튼 밖으로 끌면 패널이 이동합니다. 드롭다운은 클릭해서 선택하며, 드롭다운 위에서 마우스로 패널을 옮기려면 Alt를 누른 채 끕니다. 입력란과 볼륨 슬라이더에서는 위아래로 끌어 패널을 이동하고, 좌우로 끌어 텍스트를 선택하거나 볼륨을 조절합니다.

패널 위치는 이 브라우저에서 영상 간에 공유됩니다. 각 모드의 조작부는 항상 펼쳐져 있습니다. 창보다 긴 패널은 위로 끌어 아래쪽 버튼을 사용할 수 있습니다. 제목 옆 **위치 초기화**를 누르면 오른쪽 위로 돌아갑니다.

키보드로는 패널에 초점을 두고 방향키로 위치를 옮깁니다. 터치 화면에서는 한 손가락으로 패널을 이동합니다.

확장 프로그램은 자동 설치하거나 스토어에 게시되지 않습니다. 삭제하려면 확장 관리 페이지에서 제거하세요. 제거하면 저장한 연습 설정도 사라질 수 있습니다.

### Microsoft Edge

Edge에서는 `edge://extensions`를 열고 개발자 모드를 켠 뒤 **압축 풀린 파일 로드**로 같은 폴더를 선택할 수 있습니다. 현재 패키지의 실제 Edge 재생 검증도 별도로 필요합니다.

## 연습 흐름

- **영상 속도**에서 0.25×, 0.5×, 0.75×, 1×를 선택합니다. **− / +**로는 0.25–2.00× 사이에서 0.05씩 조절할 수 있습니다. 드럼 모드에서는 **연습 속도**에서 같은 방식으로 조절합니다.
- **구간 반복**에서 현재 재생 위치를 **시작 지정**과 **종료 지정**으로 표시합니다. 유효한 종료 지점을 지정하면 반복이 자동으로 켜집니다. 각 버튼 옆 입력란에 `분:초.소수` 또는 초 단위로 직접 입력할 수도 있습니다. 시간을 입력한 뒤 Enter로 적용하고, 입력 도중 Esc를 누르면 이전 값으로 돌아갑니다. 최소 구간 길이는 0.2초입니다.
- **드럼만 연습 → 템포 · 드럼**에서 원곡 BPM을 입력하거나, 원하는 연습 박자에 맞춰 **탭 템포**를 누릅니다. 두 번째 탭부터 최근 두 탭의 간격으로 연습 BPM과 재생 중인 드럼 템포를 갱신합니다. 원곡 BPM과 연습 BPM은 정수로 표시하고, 원곡 BPM 입력란의 화살표는 1 BPM씩 조절합니다. 현재 배속으로 환산한 원곡 BPM은 영상별로 저장됩니다(30–300).
- **드럼만 연습**을 누르면 영상이 멈추고 드럼이 바로 시작됩니다. 드럼은 `원곡 BPM × 연습 배속`에 맞춰 연주합니다. 예를 들어 123 BPM을 0.8×로 연습하면 화면에는 98 BPM으로 표시되고 드럼은 98.4 BPM으로 연주합니다.
- **영상 연습**으로 돌아오면 드럼이 멈추고 영상은 멈췄던 위치에서 이어집니다. 이미 반복 종료 지점을 지난 상태라면 그 위치에서 계속 재생하고, 종료 지점 앞으로 되돌아가면 다시 구간을 반복합니다.
- 시작·종료 시간, 반복 여부, 배속, BPM, 패턴, 볼륨은 영상별로 자동 저장됩니다. 다시 방문해도 자동으로 재생하지는 않습니다.

## 단축키

유튜브 탭에 포커스가 있을 때만 동작하며 검색창, 댓글, 패널 입력란 등에서 입력 중이면 무시합니다. 브라우저·운영체제와 충돌하면 패널 버튼을 사용하세요. 현재 버전은 키 재지정 기능이 없습니다.

| 키 | 기능 |
|---|---|
| Alt + Shift + A / B | 현재 위치를 각각 시작 / 종료 지점으로 지정 |
| Alt + Shift + L | 반복 켜기 / 끄기 |
| Alt + Shift + ← / → | 배속 −0.05 / +0.05 |
| Alt + Shift + Space | 현재 모드 시작 / 정지 |

## 드럼

**템포 · 드럼 → 스타일**에서 4/4 반주를 고릅니다. 연주 중에도 같은 박자를 이어 가며 스타일을 바꿀 수 있고, 선택은 영상별로 저장됩니다.

| 스타일 | 리듬 특징 |
|---|---|
| 기본 8비트 | 8분음표 하이햇 위에 1·3박 킥과 2·4박 스네어 |
| 록 | 강한 스네어와 3박에서 연달아 두 번 치는 킥 |
| 셔플 | 각 박을 셋으로 나눠 첫째와 셋째에 치는 하이햇 |
| 그루브 | 엇박 킥과 3박 뒤에 가볍게 넣는 스네어 |
| 펑크 | 엇박에 강세를 둔 16분음표 하이햇과 스네어 고스트 노트 |
| 스트레이트 16비트 | 일정한 16분음표 하이햇과 2·4박 스네어 |

Web Audio로 킥·스네어·하이햇을 합성하며 외부 샘플을 다운로드하지 않습니다. 원곡 BPM은 30–300이며 드럼 템포는 배속에 비례합니다. 원곡과 드럼을 동시에 재생하거나 첫 박을 맞추는 기능은 없습니다. 영상 자체의 재생 버튼을 누르면 드럼은 멈추고 영상 모드로 돌아갑니다.

## 개인정보 및 권한

- 유일한 API 권한: `storage`.
- 실행 대상: `https://www.youtube.com/*`. 일반 `/watch` 페이지에서만 패널을 표시합니다.
- 영상 ID별 연습 설정을 `chrome.storage.local`에 저장합니다. 계정 동기화, 분석 수집, 서버 전송은 없습니다.
- 마이크·카메라·다운로드·탭 목록 접근 권한을 요구하지 않습니다.
- 페이지에서 보이는 비디오 요소를 조작합니다. 영상 다운로드나 광고 우회 기능이 아닙니다. 광고 감지 중에는 연습을 중지합니다.

## 지원 범위와 확인할 점

- 일반 데스크톱 YouTube 영상용입니다. Shorts, 라이브 스트림, 임베드 플레이어, 모바일 사이트는 지원 대상이 아닙니다.
- 구간 반복은 브라우저 탐색(seek) 기반입니다. 디코딩·네트워크 상황에 따라 짧은 틈이 생길 수 있으며 **샘플 단위 무음 없는 반복을 보장하지 않습니다**.
- 드럼은 전경 탭에서 사용하는 것을 권장합니다. 백그라운드 탭 제한·절전·기기 잠금은 리듬을 끊을 수 있습니다. 오디오가 중단되면 다시 시작하세요.
- YouTube의 DOM 변경, 광고, 다른 확장과의 충돌은 실제 사이트에서 검증이 필요합니다. 지원되지 않는 배속은 사용자에게 알리거나 실제 수락된 값으로 표시합니다.
- 여러 유튜브 탭을 동시에 드럼 모드로 켜지 마세요. 다른 탭의 드럼을 자동으로 끄지는 않습니다.

## 개발 및 테스트

별도 빌드나 npm 의존성이 없습니다. Node 20+에서:

```
npm test
npm run check
npm run package
```

`tests/fixture.html`은 로컬 UI 테스트용입니다. 확장의 content script를 일반 페이지에 로드하고 가짜 비디오 시간·저장 API를 제공합니다. 실제 유튜브·미디어 디코딩 검증을 대체하지 않습니다.

계산·패턴·오디오 생명주기는 Node 테스트로, 패널 배치와 탭 입력 후 드럼 음표 간격은 Edge의 로컬 테스트 페이지에서 확인했습니다. 배포 전 다음 항목을 실제 유튜브 영상에서 확인하세요.

- 실제 영상에서 0.70×/0.75× 등 세밀한 배속 반영 및 음높이
- 구간 반복과 종료 지점 근처 seek, 시작·종료 시간 직접 입력
- 영상 ↔ 드럼 전환 시 현재 위치에서 이어 재생, 빠른 클릭
- 영상 이동·뒤로가기·광고 전환 시 오래된 드럼/구간이 남지 않는지
- 전체화면과 좁은 화면, 댓글/검색창에서 단축키가 개입하지 않는지
- 새로고침 후 현재 시작·종료 지점과 배속·BPM 복원
